# PRODUCT

## Product

rtools is a personal cross-platform toolset. Its Windows desktop application
combines a fast personal task list with local-network file transfer, device
synchronization, AI access through MCP, reminders, and data import/export.

## Audience and context

The current user is a single technical professional working primarily on
Windows 11. The application is used throughout the day for quick capture,
scanning a moderately long task list, completing work, and occasionally
configuring synchronization or transfer features.

## Product truth

- Tasks remain the primary content and interaction.
- Existing task data and cross-device synchronization are preserved.
- Transfer, MCP, updates, reminders, and import/export remain available.
- The desktop client is self-hosted and personal; account-heavy enterprise
  patterns do not belong in the primary workflow.
- The established visual reference is Things 3, expressed with native Windows
  11 materials and Fluent controls.

## Success

A user can open the app, understand the current workload, capture a task,
complete a task, and reach secondary tools without a layout shift or unnecessary
visual noise. The interface should feel calm during repeated daily use.
