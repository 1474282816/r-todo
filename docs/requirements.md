# 待办软件 需求文档 v1.0

## 1. 产品定位

极简跨端待办工具。核心场景：**在桌面直接管理日常工作**，无需打开主 App。风格对标 **Things 3**。

## 2. 平台与形态

| 平台 | 主 App | 桌面形态 |
|---|---|---|
| Windows | ✅ | 嵌入桌面（类 Rainmeter），毛玻璃背景，置底不占任务栏 |
| Android | ✅ | 多尺寸小组件（2x2 / 4x2 / 4x4），大尺寸可勾选+快速添加 |
| iPad | ✅ | iPadOS 小组件，尺寸适配同上 |

## 3. 数据模型

**Task**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | uuid | 主键 |
| `title` | string | 必填 |
| `priority` | enum | 高/中/低 |
| `remind_at` | datetime? | 可空 |
| `remind_offset_min` | int | 提前提醒分钟数，默认 15 |
| `repeat_rule` | string? | RRULE (RFC 5545) |
| `completed_at` | datetime? | 可空 |
| `created_at` | datetime | |
| `updated_at` | datetime | 用于同步冲突判定 |

## 4. 核心功能

### 4.1 任务列表

- 单一全局列表，无分组无 Tab
- 未完成在上，已完成在下
- **已完成任务次日 0:00 自动隐藏**（数据保留）
- 排序：优先级 → 提醒时间 → 创建时间

### 4.2 优先级视觉化

参考 Things 3：任务左侧彩色圆点或细竖条

- 高 = 红
- 中 = 黄
- 低 = 灰

### 4.3 重复任务

底层 **RRULE (RFC 5545)** 存储。UI 提供预设：

- 每天
- 每周某几天（多选）
- 每月某日
- 每 N 天 / 每 N 周
- 工作日 / 周末

### 4.4 提醒

- 系统级通知（弹窗 + 声音）
- 默认提前 15 分钟，全局可配，单任务可覆盖
- ❌ **不做 Snooze**

### 4.5 桌面形态交互（三端共性）

支持：

- ✅ 查看列表（未完成 + 今日已完成）
- ✅ 勾选/取消完成
- ✅ 快速添加（至少标题）
- ✅ 点击进入编辑

复杂编辑（重复规则、提醒时间）走主 App。

### 4.6 Windows 桌面嵌入细则

- 无边框、置底（挂到 WorkerW，Win+D 不隐藏）
- 毛玻璃（Acrylic / Mica）
- 可拖动、可调尺寸，位置尺寸记忆
- 开机自启

### 4.7 删除

**硬删除**，无回收站

### 4.8 云同步（自托管友好）

- **本地优先**：不登录也能完整使用
- **登录方式**：填写「服务端地址 + 密钥」即可，无账号体系
- **同步策略**：Last-Write-Wins，按 `updated_at` 判定
- **实时性**：能实时最好

## 5. 视觉规范

- 风格基准：**Things 3**
- 主题：跟随系统深浅色
- 信息密度：低
- 字体：系统默认无衬线
- 图标：极少

## 6. 明确排除

- ❌ 番茄时钟
- ❌ 备注 / 描述
- ❌ 子任务
- ❌ 标签 / 项目 / 分组
- ❌ 附件
- ❌ 协作 / 分享
- ❌ 统计报表
- ❌ 账号体系（邮箱/手机/第三方登录）
- ❌ Snooze
- ❌ 回收站
